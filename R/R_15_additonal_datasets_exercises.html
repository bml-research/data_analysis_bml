You can practice your ‘R’ skills with these datasets:

  • load a dataset in R; check the separator first and decide which code you need to load the data in RStudio

  • each dataset contains missing data; remove these from the dataset first before analysing and/or visualising in graphs

    • HINT: check columns that should have numbers, but contain character type data

  • group data for different variables and use them for graphs, such as boxplots and barplots

  • filter for certain conditions (e.g. Probability SP > 0.7, #Exons < 10,…)

  • use (statistical) calculations for several variables and for different groups (e.g. ‘Gene family’, ‘Signal petpide’, etc.) try to create the following graphs (including titles, axis titles, etc.):

  • Boxplot:

    • Mol. weight for monomers, dimers, trimers,….

    • Probability SP for signal peptides (SPI, SPII,….)

    • GC-content for Gene family

  • Barplot (with the Gene symbol on the x-axis):

    • Average Mol. weight for a particluar Gene family

    • Average isoelectric point for a localisation

  • XY-scatterplot (for only Motor proteins):

    • GC-content vs gene size

    • Gene size vs #exons for membrane proteins

    • Pos. residues vs Neg. residues for proteins containing a SPI signal peptide

NOTE: these analyses are not very meaningful biologically, but these exercises are meant to help you analyse and visualize data in R.
